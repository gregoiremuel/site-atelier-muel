# Site Grégoire Muel (sites internet) : instructions pour Claude

Site de Grégoire Muel EI pour son activité de création et refonte de sites (commerces, artisans, entreprises). Le nom « Atelier Muel » est réservé à sa future joaillerie : il n'apparaît pas sur ce site. Le dépôt et le projet Cloudflare gardent le nom technique `site-atelier-muel`. Moteur « agence » de la méthode de Greg (dépôt `gregoiremuel/kit-sites-boutiques`, `METHODE.md`).

- Lis `LISEZMOI.md` avant toute tâche : contenu, ce qui reste à valider, mise en ligne, démonstrations.
- Le contenu de départ est `contenu-initial.json` ; une fois en ligne, il vit dans la mémoire du site (Cloudflare KV) et se modifie depuis la page de modification (`/admin`).
- Avant de livrer ou de déployer : `npm run verifier` sans erreur, `npm test` tout « ok », `npm run apercu`, démo essayée.
- Règles : ne rien inventer (tous les prix, 590 € / 1 290 € / 1 900 € et abonnements 19 € / 49 €, sont des propositions à valider) ; Opéria cité seulement avec leur accord ; la Fromagerie La Fontaine n'apparaît jamais, ni sous son nom ni en démonstration (pas signée) ; rien de la Maison Tcheskiss ; aucune démonstration de joaillerie (ce métier est réservé à Atelier Muel) ; aucune photo de banque d'images présentée comme un travail réel ; mentions légales à faire relire ; aucun identifiant ni secret dans le dépôt (Secrets Cloudflare).
- Toute amélioration du moteur se reporte dans `modeles/agence-operia` du kit (et dans `site-operia` si utile), avec `npm run verifier` et `npm test` relancés.
- Un site, une identité : ce site ne doit ressembler à aucun autre site de la méthode (couleur, polices, mise en page, formes) et son interface doit rester cohérente avec le métier (règle et registre des styles dans `METHODE.md`, partie 3). Toute évolution du style se vérifie contre les autres sites avant livraison.
- Avec Greg : français, tutoiement, direct. Réponse finale en trois parties : Réponse claire ; Niveau de confiance (0.0 à 1.0, avec la raison) ; Réserves clés.
- Design et preuve : `docs/REGLES-DESIGN.md` fait foi (tailles, goût, preuve humaine). Avant livraison, lancer aussi `npm run rendu` (serveur local lancé) ; texte jamais sous 14 px, titres plafonnés, rien de caché au chargement.
- Conformité (RGPD, LCEN, cookies) et titres Google : `docs/CONFORMITE.md` fait foi (cas de Greg, tableau, « à remplir ») ; refaire `docs/PROMPT-CONFORMITE.md` si un traceur, un service ou un champ de formulaire s'ajoute. Jamais de champ légal inventé ; le texte de confidentialité décrit ce que le site fait vraiment. Pas de conseil juridique.
- Direction artistique : les skills du kit (`design-taste-frontend`, `impeccable`, `frontend-ui-engineering`, `apple-design` et autres d'Emil Kowalski, `.claude/skills/` du dépôt `kit-sites-boutiques`) s'utilisent pour toute évolution visuelle ; `DESIGN.md` et `PRODUCT.md` décrivent le style actuel ; `docs/REGLES-DESIGN.md` (plafonds de titres) l'emporte en cas de conflit.
